This is a real LaTeX editor. Edit the source on the left, press
\textbf{Build} to compile it to a PDF with tectonic, and the compiled
document appears in the PDF tab on the right.

\section{Math}

Inline math like $E = mc^2$ renders in the compiled PDF, and so does
display math:
\[
  \int_0^\infty e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}.
\]

\section{Your project}

Open the file tree (the menu button, top-left) to add files and folders,
upload existing ones, or drag things around. Everything you create is part
of this project and compiles together.

\section{Let the agent write it}

Use the agent chat below to draft sections, fix a compile error, or restyle
the whole document. It can read and edit every file in this project.
